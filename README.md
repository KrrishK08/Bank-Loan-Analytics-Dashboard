# Bank Loan Analytics Dashboard | Power BI

## Project Overview
This project presents an interactive Bank Loan Analytics Dashboard developed using Microsoft Power BI. The dashboard analyzes loan applications, funded amounts, repayments, borrower characteristics, and loan performance to generate meaningful business insights.

## Business Objectives
- Analyze overall bank loan application performance.
- Track total funded amounts and repayments.
- Understand monthly loan application trends.
- Evaluate good loan and bad loan performance.
- Analyze loan distribution by state, purpose, term, and home ownership.
- Monitor average interest rates and Debt-to-Income (DTI) ratios.
- 
## Dashboard Pages
### 1. Summary Dashboard
Provides an overall view of bank loan performance through:
- Total Loan Applications
- Total Funded Amount
- Total Amount Received
- Average Interest Rate
- Average DTI Ratio
- Monthly Loan Application Trends
- Loan Applications by State
- Loan Applications by Term
- Loan Applications by Home Ownership
- Loan Applications by Purpose
- 
### 2. Overview Dashboard
Focuses on loan quality and repayment performance through:
- Good Loan Applications
- Bad Loan Applications
- Good and Bad Loan Funding Analysis
- Funded Amount vs Repayment
- Loan Application Status
- Average Interest Rate by Loan Status
- Average DTI Ratio by Loan Status
